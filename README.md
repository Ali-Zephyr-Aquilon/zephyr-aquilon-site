# Zephyr Aquilon — website

Static three-page site. No build step. Publish the **contents** of this folder to the repository root (GitHub Pages: Settings → Pages → main / root).

## Files
```
index.html         Overview (hero animation, key figures, problem)
technology.html    Platform, diagrams, hardware, competition
company.html       Market, roadmap, team, contact form
css/styles.css     shared styles
js/site.js         animations, mobile menu, contact form
assets/            photos
og-image.png       social preview card
CNAME              custom domain (www.zephyraquilon.com)
robots.txt, sitemap.xml, googled1d30edba5800591.html (Search Console), .nojekyll
```

## Contact form
Connected to Formspree (`https://formspree.io/f/mbgrvekr`, set in js/site.js). It only works from the live web address — test after publishing.

## After publishing
Resubmit sitemap.xml in Google Search Console so the two new pages get indexed.
